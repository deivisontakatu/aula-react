# Projeto integrador — React Lab

## 1. Objetivo

Consolidar os conceitos estudados em uma proposta de aplicação de catálogo didático. O foco deste documento é orientar o planejamento, a implementação feita em aula e a reflexão final; o repositório de material didático não precisa conter uma aplicação pronta.

## 2. Requisitos mínimos

A aplicação desenvolvida durante as aulas ou como exercício deve contemplar:

- Componentes reutilizáveis.
- JSX e expressões JavaScript.
- Props para personalizar cards.
- Estado para acompanhar interações.
- Renderização condicional e listas com `key`.
- Formulário simples ou filtro de pesquisa.
- Pelo menos uma interação com efeito ou dado externo, conforme o ritmo da turma.
- Interface clara e mensagens para estados vazios ou de erro.

## 3. Roteiro de desenvolvimento

1. Descreva o público e o propósito do catálogo.
2. Esboce a interface e identifique componentes.
3. Organize os dados de conceitos.
4. Implemente os cards com props.
5. Acrescente interações por meio de estado e eventos.
6. Inclua pesquisa, filtro ou formulário.
7. Se houver tempo, adicione navegação ou consumo de API.
8. Teste os estados principais e revise a organização do código.
9. Apresente o resultado e explique as decisões tomadas.

## 4. Critérios de conclusão

- A interface atende aos requisitos mínimos definidos em aula.
- Os componentes têm responsabilidades claras.
- Os dados são passados e atualizados de forma adequada.
- As interações principais funcionam.
- O aluno consegue explicar os conceitos usados.
- A aplicação apresenta mensagens compreensíveis para situações relevantes.

## 5. Perguntas para reflexão

- Quais componentes você reutilizou e por quê?
- Qual dado foi armazenado em estado?
- Onde você usou renderização condicional?
- Como garantiu chaves estáveis na lista?
- Qual foi o erro mais difícil de resolver?
- O que você melhoraria com mais tempo?

## 6. Checklist final

- [ ] Implementei os requisitos combinados.
- [ ] Testei as principais interações.
- [ ] Consigo explicar os conceitos usados.
- [ ] Identifiquei pelo menos uma melhoria futura.
