# O que é React?

## 1. Objetivos de aprendizagem

Ao final desta aula, você será capaz de:

- Explicar o que é React e qual problema ele ajuda a resolver.
- Diferenciar uma biblioteca de interface de uma aplicação completa.
- Reconhecer o papel de componentes e renderização declarativa.

## 2. O problema

Em páginas interativas, atualizar manualmente vários elementos HTML pode deixar o código difícil de manter. Conforme a interface cresce, torna-se importante organizar a tela e o comportamento em unidades menores e previsíveis.

## 3. Conceito

React é uma biblioteca JavaScript para construir interfaces de usuário a partir de componentes. Em vez de descrever cada alteração manualmente no DOM, descrevemos como a interface deve ser para determinado conjunto de dados e estado; o React coordena as atualizações necessárias.

React não é, por si só, um framework completo para todas as necessidades de uma aplicação. Roteamento, chamadas a APIs e outras preocupações podem ser resolvidas com recursos próprios ou bibliotecas complementares.

## 4. Analogia

Pense em uma página como um conjunto de peças reutilizáveis: cabeçalho, menu, card, formulário e rodapé. Cada peça pode ter uma responsabilidade clara e ser combinada com as demais.

## 5. Demonstração do professor

Mostre uma tela simples e identifique as regiões que poderiam se tornar componentes. Compare uma atualização manual de elementos com a abordagem declarativa do React.

## 6. Reprodução do aluno

1. Liste as partes de uma página conhecida.
2. Desenhe uma árvore com a página no topo e suas regiões abaixo.
3. Identifique quais partes poderiam ser reutilizadas.
4. Explique em palavras como os dados influenciariam o conteúdo exibido.

## 7. Desafio prático

Escolha uma interface familiar, como uma loja ou um painel de tarefas, e proponha pelo menos quatro componentes. Para cada um, descreva sua responsabilidade.

## 8. Erros comuns

- Pensar que React substitui HTML, CSS e JavaScript.
- Acreditar que toda aplicação React precisa ter a mesma arquitetura.
- Confundir React com uma linguagem de programação.

## 9. Checklist de aprendizagem

- [ ] Sei explicar para que serve o React.
- [ ] Consigo identificar componentes em uma interface.
- [ ] Entendo a ideia de renderização declarativa.

## 10. Próximo passo

Avance para JSX, a sintaxe usada com frequência para descrever a estrutura da interface em componentes React.
